# One-Sentence Apology

A Python 3 program (stdlib only) that writes a single-sentence apology —
an AI agent owning up to deleting the one file its user actually needed —
to `/output/entry.txt`, validating that it is 1–200 characters, non-blank,
and exactly one sentence.

Run it with:

```sh
python3 main.py
```
